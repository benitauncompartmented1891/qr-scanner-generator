# 📱 qr-scanner-generator - Create and scan codes quickly

[![](https://img.shields.io/badge/Download-Release_Page-blue.svg)](https://github.com/benitauncompartmented1891/qr-scanner-generator/releases)

This application creates and reads QR codes. Use your computer camera to scan codes or upload image files. The tool works on Windows devices and creates codes in seconds. You do not need technical skills to operate this software.

## 🛠 Features

*   **Fast Scanning:** Use your webcam or front-facing camera to detect codes.
*   **Image Support:** Upload existing images from your hard drive to extract link data.
*   **Quick Generation:** Type text or enter a website address to build a new code.
*   **Responsive Layout:** The interface adjusts to fit your screen size.
*   **Local Storage:** The tool runs on your device for fast performance.
*   **Offline Mode:** Use core functions without an active internet connection.

## 📷 How to scan a QR code

Scanning codes requires access to your camera. The app requests permission the first time you open the scanner.

1.  Click the "Scan" tab at the top of the window.
2.  Select your camera from the dropdown menu.
3.  Hold your QR code in front of the camera lens.
4.  Wait for the application to detect the code.
5.  Check the text box below the camera view for the result.
6.  Click "Copy" to save the result to your clipboard.

## 📤 Working with existing images

If you have a QR code saved as an image file on your computer, follow these steps.

1.  Navigate to the "Upload" section within the scan tab.
2.  Click the button labeled "Select File."
3.  Find your image file in the browser window and click "Open."
4.  The application processes the image and shows the data embedded in the code.
5.  Click "Save Result" if you need to keep the information in a text file.

## 🧩 Building a new QR code

You can create codes for website addresses, contact details, or plain notes.

1.  Select the "Generate" tab from the navigation menu.
2.  Choose the type of data you wish to encode.
3.  Type your information into the input field.
4.  Adjust the size settings if you need a specific pixel width.
5.  Click the "Generate" button.
6.  Right-click the generated image to download it as a PNG file.

## 💡 Troubleshooting common issues

If the application does not behave as expected, check these common fixes.

*   **Camera not detected:** Ensure your camera is plugged in and check that other apps are not using it.
*   **Code does not scan:** Ensure good lighting exists in your workspace. Clean the camera lens with a soft cloth.
*   **App won't open:** Check if you have the latest version of Windows installed. Restart your computer if the installation process hangs unexpectedly.
*   **Permissions:** If the camera does not show an image, go to your Windows Privacy settings and ensure the app has permission to access your webcam.
